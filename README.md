## Learning Path

The repository is organized into 15 learning modules:

1. **Python Basics** — syntax, variables, data types, input and output
2. **Conditions** — comparison operators, logical operators and conditional logic
3. **Loops** — `for`, `while`, ranges and iteration
4. **Collections** — lists, tuples, sets and dictionaries
5. **Functions** — reusable functions, parameters, arguments and return values
6. **Files** — reading, writing and working with files
7. **Errors & Exceptions** — exception handling and defensive programming
8. **Object-Oriented Programming** — classes, objects, methods and attributes
9. **Libraries & Data** — working with Python libraries and structured data
10. **Testing & Debugging** — validating code and identifying errors
11. **Automation & Practical Python** — applying Python to repeatable tasks
12. **Git & Version Control** — tracking and managing code changes
13. **Projects & Practice** — combining concepts in practical exercises
14. **Code Quality & Best Practices** — readability, organization and maintainability
15. **Professional / Soft Skills** — supporting technical work in a professional environment
